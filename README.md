# WikiSearch

laboratory work 2 OOP

Консольная программа для поиска статей в русской Википедии. Пользователь вводит запрос, программа показывает найденные статьи и открывает выбранную в браузере.

## Возможности
- поиск через API Википедии (`ru.wikipedia.org/w/api.php`)
- вывод до 10 статей с кратким фрагментом текста
- открытие выбранной статьи в браузере
- обработка ошибок: пустой запрос, нет результатов, неверный номер статьи, нет интернета
- выход командой `exit`

## Запуск
1. Открыть проект в IntelliJ IDEA (Maven подтянет библиотеку Gson из `pom.xml`)
2. Запустить класс `Main`

## Классы
- `Main` — точка входа
- `WikiSearchApp` — главный цикл программы
- `ConsoleInput` — ввод запроса и номера статьи
- `WikiApiClient` — HTTP-запрос к API Википедии
- `ResponseParser` — разбор JSON-ответа с помощью Gson
- `SearchResult` — найденная статья (заголовок, pageid, фрагмент)
- `ResultPrinter` — вывод результатов
- `BrowserOpener` — открытие статьи в браузере

## Технологии
Java 17, Maven, Gson
